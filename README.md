# AI Bootloader — V1.0.0
Central AI orchestration, ecosystem awareness, adaptive context engineering, and cross-project knowledge management.

Start by installing [BOOT-ROM.txt](BOOT-ROM.txt) in ChatGPT Custom Instructions. For another capable agent provide the same text and authenticated access. Load [AGENTS.md](AGENTS.md) then [BOOT.md](BOOT.md) at one commit. [NAVIGATION.md](NAVIGATION.md) maps the rest.

This is a versioned instruction/knowledge layer, not an executable autonomous background service. Actual capabilities depend on the agent and authorization. The owner explicitly permits the public repository and non-sensitive ecosystem metadata. Never store passwords, tokens, customer data, private source, or confidential config. See [ecosystem/REGISTRY.md](ecosystem/REGISTRY.md) for rules. [tests/SCENARIOS.md](tests/SCENARIOS.md) specifies behavior; run the validator from the root with python3 tests/validate.py. Structural checks do not prove independent agent adherence.
